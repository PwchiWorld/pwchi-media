# PwchinWorld Worldbuilding — Project Roadmap & To-Do List

**Project Goal**: Build a rich, consistent, and expandable world for PwchinWorld (Pwchi) with Mira as a central character, while maintaining strict continuity with existing canon.

**Repository**: https://github.com/PwchiWorld/pwchi-media/tree/main/pwchinworld-worldbuilding

- Skill `pwchinworld-worldbuilding` created and installed.
- Core structure and principles defined.
- Central character **Mira** established (visual reference available).
- Access to official sources: pwchin.com/pwchi-clan/ and origin story.
- GitHub integration active for version control and backup.

## Roadmap (Phases)

### Phase 1: Foundation & Canon Audit (Current)
- Review and document all existing canon from official sources.
- Create "Canon Bible" (summary of known lore, clans, characters, rules of the world).
- Identify gaps and areas for safe expansion.
- **Status**: In Progress

### Phase 2: Clan Deep Dives
- Fully document all 7 Pwchi Clans (philosophy, symbols, aesthetics, strengths, role in the world).
- Establish inter-clan relationships and conflicts.
- Create visual and narrative identity for each clan.

### Phase 3: Character System
- Expand **Mira**’s full character bible (backstory, personality, abilities, arc).
- Document existing legendary characters.
- Create new supporting characters that fit the world.

### Phase 4: World Building
- Map major locations, realms, and environments.
- Define rules of PwchinWorld (physics, magic/technology, society, dimensions).
- Create ecosystems, cities, and points of interest.

### Phase 5: Narrative & Adventures
- Develop major story arcs and adventure hooks.
- Create quests, conflicts, and plotlines involving Mira and the clans.
- Design "playable" scenarios or lore drops.

### Phase 6: Visual & Asset Integration
- Generate consistent visual references and moodboards.
- Link with existing assets (Mira image, logo, etc.).
- Prepare for media expansion (stories, animations, games).

### Phase 7: Maintenance & Expansion
- Ongoing lore consistency checks.
- Versioned updates to Canon Bible.
- Community / creator guidelines (if applicable).
