# PWCHI Content Automation System v1

Purpose:

Turn PWCHIN assets, Demo Pack material and WordPress ecosystem content into repeatable social/media output.

Core funnel:

**See Pwchies -> Want one -> Download Demo Pack -> Create a Pwchi -> Request Guided Tour**

## 1. Inputs

Content generation should use these sources:

- `landing/img/` - local visual assets for landing and social
- `demo-pack/pwchi-demo-pipelines.zip` - downloadable Demo Pack
- `demo-pack/manifest.md` - promise check for the Demo Pack
- `wordpress-drafts/free-pwchi-demo-pack-page.html` - WordPress-ready page source
- `strategy/current-operating-status.md` - current operating state
- `strategy/ecosystem-synthesis.md` - ecosystem map
- `agents/pwchi-grok-video-content-agent.md` - agent instructions
- WordPress Media Library - source of existing public media
- WordPress pages and posts - source of ecosystem context

## 2. Outputs

Each automation batch can produce:

- TikTok / Reels / Shorts script
- Grok image-to-video prompt
- Gemini / Veo photo-to-video prompt
- caption variants
- X post
- Pinterest pin title and description
- Reddit post
- Substack note or article outline
- WordPress draft post
- production checklist

## 3. Automation Levels

### Level 1: Manual Assisted

Codex creates content batches.

Human:

- selects asset
- generates video in Grok / Gemini
- posts manually
- reviews copy

This is the current recommended level.

### Level 2: Draft Automation

Codex creates:

- WordPress draft posts
- Markdown content batches
- content calendars
- asset registries
- tracker updates

Human approves before publishing.

### Level 3: Scheduling Tools

Possible later:

- Buffer
- Metricool
- Meta Business Suite
- YouTube Studio
- Pinterest scheduler
- Make / Zapier

Use only after we know which content converts.

### Level 4: Feedback Loop

Possible later:

- collect post URLs
- collect views / saves / comments
- classify winning hooks
- generate next batch from winners

## 4. Human Approval Rules

Do not automatically publish:

- WordPress pages
- WordPress posts
- Reddit posts
- paid offer changes
- legal / pricing claims
- claims about services not currently available

Drafts are allowed.

Local Markdown generation is allowed.

## 5. Safe Messaging Rules

Use:

- Free Pwchi Demo Pack
- Download Demo Pack ZIP
- One PNG. Many creative outputs.
- Want your own Pwchi?
- Create a Pwchi
- Request a Guided Tour
- original source image
- origin asset
- character pipeline
- brand avatar
- visual continuity

Avoid:

- guaranteed copyright safe
- no copyright risk
- official affiliation with Grok, xAI, Gemini or Google
- production-ready 3D models unless actually delivered
- "we will create for everyone who comments"
- copying famous brand styles

## 6. Daily Workflow

1. Choose one asset from `asset-registry.md`.
2. Choose one campaign angle.
3. Generate one content batch using `batch-request-template.md`.
4. Generate video in Grok and/or Gemini manually.
5. Select best video output.
6. Post to 1-3 platforms.
7. Log the post in `posting-tracker.md`.
8. Record lessons.

## 7. Weekly Workflow

1. Pick 5-7 assets.
2. Generate weekly calendar.
3. Produce 5 short-form scripts.
4. Produce 2 Reddit posts.
5. Produce 1 Substack note/article.
6. Produce 10 Pinterest pins.
7. Review what can be posted manually.
8. Log results.
