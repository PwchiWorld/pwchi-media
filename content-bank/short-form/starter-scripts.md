# PWCHIN Short-Form Starter Scripts

## Script 1: Want Your Own Pwchi?

Hook:

Would you turn yourself into a Pwchi?

Script:

0-2s: Show a strong Pwchi character.

2-5s: Text: "This started as one PNG."

5-9s: Show possible outputs: avatar, sticker, NPC, merch, companion.

9-13s: Text: "One character. Many creative futures."

13-16s: CTA: "Comment PWCHI if you want one."

Caption:

One PNG. Many creative outputs. Would you want your own Pwchi?

## Script 2: One PNG, Five Futures

Hook:

This tiny character can become five different things.

Script:

0-2s: Show original PNG.

2-4s: Flash "3D concept".

4-6s: Flash "Talking avatar".

6-8s: Flash "Sticker pack".

8-10s: Flash "Game NPC".

10-12s: Flash "Merch concept".

12-15s: Ask: "Which one should I build first?"

Caption:

A Pwchi is not just an image. It is a starting point.

## Script 3: Free Demo Pack

Hook:

I made a free demo pack for turning one PNG into a character pipeline.

Script:

0-3s: Show demo pack cover or hero image.

3-6s: Show sample Pwchi.

6-10s: Show pipeline labels.

10-14s: Text: "3D, avatar, NPC, stickers, merch."

14-18s: CTA: "Comment DEMO or check the link."

Caption:

Want to learn the Pwchi pipeline? Start with the free Demo Pack.

## Script 4: Freelancer Angle

Hook:

Freelancers: this could become a character service.

7-11s: Show outputs: avatar, stickers, merch, NPC.

## Script 5: Comment To Pwchi

Hook:

Drop one word and I might turn it into a Pwchi.

Script:

0-3s: Show comment or prompt word.

3-8s: Show character reveal.

8-12s: Add name and clan.

12-15s: Text: "What word should be next?"

Caption:

Comment one word. The next Pwchi might come from it.
