# PWCHIN Demo Pack Prompt Notes

Use these as starting points. Adjust the character details for your own Pwchi.

## Base Character Description

Original digital character called [NAME], from the [CLAN] clan. The character has [KEY VISUAL TRAITS], a [PERSONALITY] expression and a memorable [ACCESSORY OR MARK]. Keep the design original, readable and consistent with the source PNG.

## 3D Concept Prompt

Create a stylized 3D character concept based on this original Pwchi PNG. Preserve the character's main silhouette, face shape, color palette, costume elements and signature mark. The result should feel like a collectible digital character suitable for game concept exploration. Full body, clean lighting, neutral pose, high visual clarity, original design.

## Talking Avatar Prompt

Create a talking avatar direction for this original Pwchi character. Preserve the face, eyes, hairstyle, main colors and signature accessory. Frame the character from chest up, facing camera, expressive but not exaggerated, suitable for short-form video, AI companion experiments or social media hosting.

## Game NPC Prompt

Create a game NPC concept based on this original Pwchi PNG. Keep the character identity consistent while adapting the outfit and posture for an explorable fantasy or sci-fi world. Include a readable silhouette, clear role, simple props and an original visual direction.

## Sticker Pack Prompt

Create a sticker pack concept for this Pwchi character. Produce multiple expressive poses and emotions while preserving the same character identity, colors and signature traits. The stickers should feel fun, readable at small size and suitable for chat, Discord or community use.

## Merch Concept Prompt

Create a merch concept for this original Pwchi character. Show how the character could appear on a sticker sheet, t-shirt graphic, collectible card or small figure packaging. Keep the character original and consistent with the source image.

## AI Companion Identity Prompt

Develop an AI companion identity for this Pwchi character. Include a short personality profile, voice tone, greeting message, visual identity notes and possible use cases. Keep the character friendly, original and distinct from existing fictional brands.

## Negative Guidance

Avoid famous brand styles, protected character references and direct imitation. Do not use prompts such as "Disney style", "Pixar style", "Marvel character", "Pokemon-like" or exact names of existing characters.
