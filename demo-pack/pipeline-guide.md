# One PNG To Many Creative Outputs

## The Idea

A Pwchi begins as one original PNG character.

That PNG becomes the origin asset: the visual source that guides every next step.

The goal is not to keep generating unrelated images. The goal is to preserve identity while exploring multiple creative outputs.

## Step 1: Choose The Origin Image

Start with one clear Pwchi PNG.

Look for:

- readable silhouette
- strong face or expression
- memorable color palette
- simple costume or accessory
- enough personality to suggest a story

## Step 2: Define The Character

Write a short identity block:

- name
- clan
- personality
- visual traits
- possible role
- one sentence of lore

Example:

Name: Mova

Clan: Moon Above Clouds

Personality: quiet, curious, precise

Visual traits: violet armor, glowing forehead mark, soft blue hair

Role: sky-city messenger

Lore: Mova carries messages between floating districts after the Great Shift.

## Step 3: Pick Output Directions

Choose 2-5 outputs:

- 3D character concept
- talking avatar
- game NPC
- sticker pack
- merch mockup
- AI companion
- brand mascot
- social profile avatar

## Step 4: Write Pipeline Prompts

For each output, describe the character without copying a famous brand style.

Include:

- character identity
- visual traits
- mood
- format
- camera/framing
- output purpose

Avoid:

- "in Disney style"
- "Pixar quality"
- "like [famous character]"
- exact brand imitation

Use:

- original digital character
- stylized 3D concept
- friendly mascot
- collectible character
- game NPC concept
- animated avatar direction

## Step 5: Compare Outputs

After generating or producing outputs, compare them to the origin image.

Check:

- does the face still feel related?
- did the color palette survive?
- is the silhouette still recognizable?
- did the character keep its main accessory or mark?
- would a viewer believe these are versions of the same character?

## Step 6: Turn It Into A Deliverable

A useful Pwchi pipeline deliverable can include:

- original PNG
- identity block
- 3D concept direction
- avatar direction
- sticker or merch direction
- prompt notes
- before / after image
- next production recommendations

## Simple Workflow

Origin PNG -> Identity block -> Output prompts -> Generated tests -> Comparison -> Final direction pack
